# いろのじっけんしつ 個別整理・検証

対象は公開中の `/pikalab/color_lab/`。main `d59c366593d0660a648b0698472a11b0fab919a1` を基準に、TOP・Deep Seaの公開済み修正を保持する。

## 実装範囲

- お気に入りの4スロットを毎回作り直さず、保存・選択・削除・並べ替えを同じ要素へ反映する。保存ボタンと削除ボタンの入れ子を解消し、操作後のキーボードフォーカスを保持する。寸法・配色・並びは維持する。
- 混色予約を一つに限定。連打による重複実行を防ぎ、後から選んだ色・レシピ・タブを古い結果で上書きしない。回転・ポップ・通常の揺れの終了経路を整理し、低モーション設定を尊重する。
- 通常色更新で静的DOMを繰り返し検索しない。装備は変化したときだけ反映する。白から黒へ直接変えた際にサングラスが残る不具合と、コード形式変更だけでレシピ名が失われる不具合を修正する。
- コース終了状態を確定し、非表示のキラ演出を停止する。クリックと矢印キーのタブ移動は同じ終了経路を使う。タイムアタックは現在のお題だけを保持する。
- 保存されたカレンダー・回数・最高得点を利用前に正規化する。型の異なるJSON、重複・不正日付、数値でない回数が表示停止や誤った解放判定を起こさないようにする。
- ダイアログの背景inert・スクロール・フォーカス復帰を一括管理し、EscapeとTab循環を実装。遅延フォーカスが閉じた画面へ移動する競合を除く。レシピタブも矢印キーで選べるようにする。
- 対象ページの既存script/styleクエリ版を更新し、以前のJavaScriptのHTTPキャッシュを引き継がない。

## 教材の明確な不整合

- 「まぜる」は各RGB値の単純平均という既存仕様を維持する。保護者説明にこの方式を明記し、実際の光や絵の具を混ぜた結果の再現と区別する。
- sRGB値128は数値範囲のほぼ半分だが、線形な光量の半分ではない。「はんぶんのつよさ」と明言した2つのお題だけを「まんなかくらい」に訂正する。他のヒント・色名・得点・目標値は維持する。
- 根拠: W3C CSS Color 4 [sRGB変換](https://www.w3.org/TR/css-color-4/#predefined-sRGB)、[補間の色空間](https://www.w3.org/TR/css-color-4/#interpolation-space)。光と色材の違いについての既存説明は [Exploratorium](https://www.exploratorium.edu/snacks/colored-shadows) と整合する。

## 比較測定

同じ制御時刻・模擬DOMで元実装と候補を比較した作業回数。実機CPU、FPS、INP、電池消費の測定ではない。

|操作|元実装|候補|
|---|---:|---:|
|保存済みスロットを100回選択した際の新規要素|600|0|
|同操作の新規イベントリスナー|2,000|0|
|100回のスライダー入力のID検索|1,602|2|
|混色を10回連打した際の予約・回数加算|10・10|1・1|

色名検索は平方根を省いて距離の二乗で比較し、代表値・しきい値・判定結果を維持する。1,000組の決定的なRGB入力で元実装と一致した。修正と状態管理の追加によりソース転送量は増えるため、「バンドルを軽量化した」とは説明しない。圧縮サイズと最終CIはPRへ記録する。

## 検証

- `node --check pikalab/color_lab/script.js`
- `node --test pikalab/color_lab/*.test.*`
- `runtime-lifecycle.test.cjs` は実際の初期化・イベントハンドラーを模擬DOMで実行する。非公開状態の検査用参照だけをVM読み込み時に付加し、本番には公開しない。`COLOR_LAB_TEST_ROOT` で元実装へ同じテストを適用できる。
- `RUN_PIKALAB_COLOR_BROWSER=1 node --test pikalab/color_lab/browser-interactions.test.cjs` はCIで生成済み配信物を検査する。PC・390px・320px、保存、ドラッグ、混色、キーボード、通常/チャレンジ全10問、時間切れ、カレンダー、装備、破損保存値を対象にする。
- Nodeの模擬DOM合格を、CSS・ネイティブ操作・表示の合格とはみなさない。実ブラウザ検査、既存の初期表示比較、独立レビュー、公開後の配信物照合が揃ってから公開する。

## 自動採用しない提案

RGBの平均を物理的な光の混合へ変更すること、色名やヒントの全面改稿、知覚的な色差による採点、カードやレイアウトの改装は今回に含めない。タイムアタックの得点星を要約表示へ変える案も、既存の見せ方の変更として分離する。
