# 実験探偵ラボ｜PikaLab（v2・レビュー版）

「2つの実験を比べ、余計な違いを見つけ、条件をそろえて、結果の測り方を考える」理科ゲーム。

## 遊べる内容

| グループ | 事件 | 学習の中心 |
|---|---|---|
| はじめの事件 | 植物 / 砂糖 / ふりこ | 変える条件・そろえる条件・測る結果 |
| 光と動き | 坂道カー / 影 / 磁石 | 複数条件の見分け、結果の解釈 |
| もう一歩 | 種の発芽 / 水の蒸発 / 音の高さ | 生物・状態変化・振動の計画 |

合計**9事件・27問**。1事件は3問。事件は自由選択、全件を一度に表示せず、3件ごとに切り替えます。誤答の具体的説明、各問2段階ヒント、正答後の条件修正を実装。クリア済み事件IDはこの端末の`localStorage`にのみ保存（利用不可ならセッション中だけ）。名前・解答履歴・所要時間は記録しません。記録の消去は「あそびかた」から可能です。

## UIと教材設計

- PikaLabの暖かな研究室世界観を踏襲。紙の質感、ルーペ、実験模式図、コーラルの主要操作、紫の調査系要素。
- 飾りコピーや所要時間表示は削除。必要な説明・学習上の注意は残す。
- **調査前に正解となる条件を色で強調しない**。正解発見後のみ修正箇所を強調し、修正済みの条件を別の状態で表示。
- 比較条件は横に重複した説明を表示せず、`条件 / 実験A / 実験B`の表として提示。
- 間違いは減点せず、結果を限定して述べる（一般化しすぎない）ことも問いに含む。
- 模式図は調査予定のイラストであり、実験後の生育・影・速さ・発芽結果などを断定しない。

## ローカル動作

`index.html`, `app.js`, `cases.js`, `assets/style.css`があれば動作します。外部CDNや実行時Tailwindは使用しません。開発PC上でこのフォルダから静的サーバーを起動してください。

```sh
python -m http.server 8000
# http://localhost:8000/ を開く
node --check app.js
node --check cases.js
node --test tests/*.test.cjs
```

スタイル編集用は`tailwind.input.css`・`tailwind.config.cjs`。同梱`assets/style.css`が配信可能なビルド済みCSSです。PikaLabで既に利用中のTailwind v3を使う場合の再生成例:

```sh
npx tailwindcss@3 -c tailwind.config.cjs -i tailwind.input.css -o assets/style.css --minify
```

※ネットワークからのその場のインストールを行わず、既存の固定された依存でビルドしてください。生成CSS差分には必ず視覚回帰確認を行うこと。

## 公開・品質ゲート

- 現時点では`noindex`で、既存のScience Maker本体・トップカタログへの変更なし。
- Public側のDraft PR→CI→教材監修→Private側で承認コミット固定→本番検証、の順で進める。Publicだけのマージで本番公開済みと扱わない。
- 必須確認: 学習指導要領の範囲・実験条件とイラストの一致、320/360/390/667/768/1024/1280/1440px、キーボード・タップ、文字サイズ拡大、第三者追跡なし、CSP、PWA配信、全27問正誤・保存・再試行。
- この教材は「変える条件が1つ」の初歩的な比較実験を扱う。複数要因を調べる実験一般を否定しない。

## 画面検証の制約

この更新作業の実行環境に組織のChromium URLBlocklistポリシーが設定され、ブラウザへのページ遷移（`file://`/`http://localhost`）が制限されました。静的コード・Nodeテストは実施しますが、**更新後画面のブラウザスクリーンショットと実操作回帰は未確認**として、レビュワーによるPlaywright実ブラウザ検証を別途必要とします。以前の画面のスクリーンショットはv2の検証証拠として再利用しません。
