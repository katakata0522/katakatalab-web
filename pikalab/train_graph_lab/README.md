# 動きとグラフの司令室 — PikaLab

**開発状態：初期縦切りプロトタイプ（3ミッション）／レビュー前の独立教材**

西の駅（0m）から東の駅（1,200m）へ走る2台の列車を、指定の位置で出会わせる学習ゲーム。ミニチュア風SVG、位置—時間グラフ、条件調整、正誤とヒントが連動。PikaLabの温かい研究室デザインを踏襲し、不要な飾りテキストやステータス表示を増やさない。

## できること

1. 中央駅600mで会う — Bの速度を調整（正解24km/h）
2. 発車時刻をずらして中央駅で会う — Bの出発待ち時間を調整（正解1.5分）
3. 800m地点で会う — Aの速度を調整（正解24km/h）

各場面で操作できる変数は**1つだけ**。模型とグラフは同じ算術モデルから描かれます。遊びながら試行錯誤し、誤答した時は「次にどう調整すると近づくか」を伝えます。進捗は端末内の解決済みミッションIDだけ。広告・アフィリエイト・第三者の行動追跡は一切なし。

## ディレクトリ

- `index.html` HTML構造・学習とUIの役割
- `style.css` UI・レスポンシブ・アクセシビリティ
- `game-core.js` 位置と出会いの純関数（Node/ブラウザ共通）
- `scene.js` 2.5DミニチュアSVGと位置描画
- `main.js` ミッション状態、グラフSVG、ブラウザ操作
- `tests/core.test.cjs` 数学と境界条件のNodeテスト
- `tests/browser-review.py` 実画面の4幅・正誤・操作テスト（Python Playwright）
- `docs/IMPLEMENTATION_SPEC.md` 学習・技術・品質の仕様書

## 開発と検証

ブラウザは このフォルダを静的ホスティングして利用できます。実運用ではこれらのファイルを `pikalab/train_graph_lab/` へコピー。プレビューには別添の1ファイル版HTMLも提供します。

```bash
node --check game-core.js
node --check scene.js
node --check main.js
node --test tests/core.test.cjs
# 開発マシンにPlaywrightを導入済みの場合
python tests/browser-review.py
```

外部ライブラリ、TailwindのランタイムCDN、サーバーサイド処理は不要。既存のPikaLabで使用するVite/Tailwind環境を汚さない小さな独立ラボです。スタイルは静的CSS（テーマ変数と小さな明示的コンポーネント）に集約。外部フォント未使用。

## 誤解の防止

これは速さが一定である模型上の運動。実際の列車の信号・加減速・同一線路での衝突は再現しません。模型の2列車は別々の平行な線路を走り、**同じ線路方向の位置xに同じ時刻に到達する**ことを「出会う」とします。
