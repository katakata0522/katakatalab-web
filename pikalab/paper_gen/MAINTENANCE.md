# paper_gen 保守メモ

## 目的
このコンテンツを、文言と機能を維持したまま安全に改善するための運用ルール。

## 変更時の必須チェック
1. `node --check pikalab/paper_gen/script.js`
2. `py -3 .github/scripts/validate_pikalab.py`

## ガードレール
- 画面文言はユーザー指示なしで変更しない
- 既存機能の仕様を変更しない
- 入力バリデーションとエラーハンドリングを維持・強化する

## 回帰しやすいポイント
- ローカル参照パス（HTML内のscript/link/img）
- レスポンシブ時のレイアウト崩れ
- キーボード操作とフォーカス遷移
- LocalStorage復元時の境界値


## 専用回帰検証
- `node --test pikalab/paper_gen/script.test.js pikalab/paper_gen/tests/*.test.cjs`
- `cd pikalab && npm run build:all && npm run test:paper-e2e`
- PRの`paper-browser`ジョブは同じ基点から作った実ビルドと4画面幅で比較し、用紙種類、保存・共有、ズーム、キーボード、印刷PDFを確認する。
- `PAPER_GEN_BASELINE_ROOT`で比較対象の実ビルドを指定できる。`PAPER_GEN_PRODUCTION_URL`は公開後の通常URL・再読み込み・参照アセット照合に使う。

## 描画・保存の契約
- 原稿は表示上の1文字（書記素）を単位に数える。古い環境はコードポイントへフォールバックする。
- 行末の句読点と閉じ括弧は2文字までぶら下げ、さらに続く記号は次のマスへ送る。
- 変更したページはSVG全体で更新する。既存のtext要素数に頼る差分更新は、空欄への追記・削除を欠落させるため行わない。
- プレビューの外枠寸法は表示倍率に合わせる。印刷後は画面用のページ間隔へ戻るので再計測する。
- 共有URLの閲覧・印刷だけでは端末の下書きを書き換えない。新形式の空文字を古い互換本文で上書きしない。
- 長い共有URLはURL-safe Base64形式に切り替える（暗号化ではない）。新形式の読み込みと旧`draft`形式の互換性を保ち、上限超過の部分共有は明示して編集欄を変えない。
