# kotowaza_quiz 保守メモ

## 目的と境界
- 2モード、設定、採点式、通常の文章・配色・配置を維持する。
- 共通データは `../data/idioms.js`。問題の漢字・読み・意味を修正するとタイピング道場にも反映されるため、根拠を確認する。
- 結果評価だけは共有スタイル由来の暗い文字色が暗いカードに埋もれていたため、このアプリの既存本文色を明示する。位置・文字サイズは変更しない。
- 高さ500px以下の横向き画面は、カード外側の中断ボタン上端が6px切れていたため、ゲーム画面の上余白のみ32pxから48pxへ補正する。ボタンとカードの相対位置・各幅は保持する。
- PWA/SW・共通CSS・未公開コンテンツはこの改善の対象外。

## 問題データ
- 全179問（ことわざ81、四字熟語98）の空欄と読みは script.js の明示的な対応表を使う。漢字とかなの文字数の比率から推測しない。
- 四字熟語は前半2文字を表示する。例: 弱肉【　　】=きょうしょく、十人【　　】=といろ。追加時は後半の読みを必ず登録する。
- 既存の有効な穴位置は保持する。「【　　】の子は蛙」「失敗は成功の【　　】」もそのまま。
- 未登録語はかなだけで表示して答えとの対応を保つが、公開データには必ず明示対応とテストを追加する。
- 意味文は文字列が違うだけでは誤答と判定できない。`MEANING_OVERLAP_GROUPS` は同義語8群と、現行の短い説明文が重なる14群を選択肢候補から除外する。これらをすべて同義語と定義しているわけではない。

## 2026-10-03 内容監査の根拠
本文の大半は変更しない。以下だけ辞書に照らして補正した。
- 「実るほど頭を垂れる稲穂かな」の頭は「こうべ」: [小学館デジタル大辞泉](https://kotobank.jp/word/実るほど頭を垂れる稲穂かな-2131632)
- 「身から出た錆」は自分の悪い行い・不注意による苦しみ: [漢字ペディア](https://www.kanjipedia.jp/kotoba/0003591000)
- 「羊頭狗肉」は立派な見かけに中身が伴わないこと: [漢字ペディア](https://www.kanjipedia.jp/kotoba/0006932900)
- 「正正堂堂」の説明が語そのものの繰り返しだったため、卑怯な手段を使わず正しい態度で行動する意味を示す: [漢字ペディア](https://www.kanjipedia.jp/kotoba/0003830800)
- 同義候補の例: [猿・弘法・河童](https://www.kanjipedia.jp/kotoba/0000468700)、[一石二鳥・一挙両得](https://www.kanjipedia.jp/kotoba/0007154800)、[二兎・虻蜂](https://www.kanjipedia.jp/kotoba/0006437300)、[馬耳東風・馬の耳](https://www.kanjipedia.jp/kotoba/0005545400)
- 「急転直下」「魚心あれば水心」「晴耕雨読」の広い意味、繰り返し漢字表記（正正堂堂等）は辞書で支持されるため保持。

## 状態と入力の契約
- `idle / question / feedback / result` で操作可能な段階を明示する。採点は question で一度だけ。
- 戻る・再挑戦で世代を進め、問題送り・フォーカス・祝福演出を取り消す。コールバックは世代とタイマーIDの両方を確認する。
- スピードボーナスは単調時計で測る。タブ非表示・ページ退避中は問題経過と1500msの回答表示を止める。
- IME変換中は入力を書き換えない。確定後にNFKCとひらがなへ正規化する。長押し・修飾キーで次の問題を勝手に回答しない。
- 音声・保存領域が使えない場合もクイズを続行する。復習スコアは通常の最高点へ保存しない。
- 選択肢は候補プールを再利用し、全候補シャッフルではなく3件だけ非復元抽出する。紙吹雪50個は削除タイマー1本で管理する。

## 必須チェック
1. `node --check pikalab/kotowaza_quiz/script.js`
2. `node --test pikalab/kotowaza_quiz/tests/*.test.cjs pikalab/tests/kotowaza_quiz.test.cjs`
3. `python3 .github/scripts/validate_pikalab.py`
4. pikalabで `npm run build:all && npm run verify:build && npm run test:kotowaza-quiz-e2e`
5. `KOTOWAZA_QUIZ_BASELINE_ROOT` に同じPR基点の実ビルドdistを指定して4幅を比較する。生ソースや別の配信物で代用しない。
6. 最終headのCI・スクリーンショット・全問題/中断/復習/IME/モバイル操作を確認後、公開URLとアセットのSHA256を照合する。
