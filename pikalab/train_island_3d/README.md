# PikaLab 3D列車の島 — 実動試作 v0.2

ユーザー提示の参照画像 `image(20261016-021653).png` の**淡い黄緑の草地、クリーム色の層状の崖、トルコブルーの海、段差のある島々、ミニチュア建築と曲がる鉄道**をデザイン目標にした、実際に動く3D模型のWeb教材です。

## 使い方

- **単体体験版**：別途生成される `TrainIsland3D_体験版.html` を開くだけ。ネット不要。
- **開発ソース**：このフォルダの `index.html` を静的Webサーバーから開く。例：`python -m http.server 8000` → `http://localhost:8000/`。
- 操作：3D模型をドラッグすると視点が回る。マウスホイール、右下の `＋/－` でズーム、`⟲` で視点リセット。
- 列車A・Bの速さを変え、「列車を走らせる」を押すと模型の列車とグラフが動く。一時停止、再開、もう一度、に対応。
- 2台とも中央駅まで**1,200m**という教材上の設定。同じ速さなら同じ時間に中央駅へ到着する。グラフは出発時から進んだ距離と時間。

## 3D実装について（重要）

この作品の地形は静止画像やCanvasへの2Dイラスト貼り付けではありません。**3次元座標を持つ多角形メッシュ**で立体の島の各面を定義し、線路の3D曲線に沿って列車を実際に動かしています。カメラは投影・回転・ズームできる3Dカメラです。

- 対応端末では標準WebGL/WebGL2で三角形をGPU描画します。
- ブラウザがWebGLを管理ポリシー等で禁止した場合は、**同じ3Dメッシュを3Dカメラ投影・奥行きソートしてCanvas2Dにレンダリング**します。これは2D画像への切替ではなく、リアルタイム3D幾何のソフトウェア描画です。
- CDN、Three.js等の外部パッケージ、アクセス解析、広告、アフィリエイトを使いません。
- ライトによる明暗は面法線から近似するローポリ用のフラットシェーディングです。実写風の影・PBR材質・高度な水面やボクセル地形編集はまだありません。
- 元の参照画像の**世界観を再現したオリジナル3D試作**です。元画像とピクセル単位で一致する精密モデルではありません。元画像から3Dメッシュの完全復元はできません。

## 数学上の注意

`game.js` は距離、速さ、到着時刻の唯一の計算元です。`world3d.js` は計算した進捗率を3D曲線上の列車位置に割り当てます。2つのコースは画面内では別線路なので衝突しません。島内の線路の見た目の実寸と教材上の1,200mは、現段階では厳密な地理的縮尺ではありません。

## ファイル

- `index.html`：実行画面。初期はnoindex（本番への公開なし）。
- `style.css`：画面デザイン、レスポンシブ対応。
- `world3d.js`：3Dメッシュ、世界生成、カメラ、WebGLとCanvas2Dの3D描画、列車。
- `game.js`：速度・時間の物理モデル、グラフ、操作、結果とヒント。
- `tests/core.test.cjs`：速度、距離、曲線、地形、カメラのNode自動テスト。
- `tests/browser-check.py`：ローカルChromium自動操作・画面撮影。ユーザー端末以外の管理ブラウザはローカルURL遷移をブロックするため、テストはabout:blankへ**同一コードを注入**して実施。

## 検証/今後の課題
