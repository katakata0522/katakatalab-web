# PikaLab 3D列車の島 — v0.6（広い本島と高い離島）

**今回の中心的な変更：** 小さな段差のある島を多数並べた配置から、**広い1枚の平地＋周辺の7つの高い離島**へ地形を再設計。列車は本島の西側・東側の広い範囲を走って中央駅へ向かいます。

## 実際に遊ぶ

1. 「はやさを変える」から操作パネルへ移動する。
2. A（赤）、B（青）の速度を12〜48km/h（6刻み）で調節。
3. 「列車を走らせる」を押すと島の鉄道が動き、速度に応じて中央駅へ到着する。
4. 結果を確認し、グラフで時間と距離の対応を調べる。「もどす」で再挑戦できる。

操作：マウスドラッグ・スマホ横ドラッグでカメラ回転、Shift＋ドラッグ／スマホ2本指ドラッグで地図移動（離島の方まで移動可能）、±ボタンで拡大縮小、⟲で初期視点。ホイールはページスクロール、Ctrl/Cmd＋ホイールで拡大。画面の縦スクロールは妨げません。キーボード（矢印、Shift＋矢印、+/-、R）対応。モーション軽減設定では結果へ即時移動。名前や成績は保存しません。

## v0.6地形設計

| 観点 | v0.5 | v0.6 |
|---|---|---|
| マップ構成 | 15の小さな高低差のある島 | **1つの広くて平らな本島＋7つの高い離島** |
| A路線（3D模型単位） | 約14.74 | **約36.69** |
| B路線（3D模型単位） | 約26.96 | **約35.07** |
| 家・風車 | 島ごとに点在 | 本島に5軒の家、離島に家2軒と風車1基 |
| 森 | 主に小島に分散 | 本島の複数の地域に植林、離島にも森を配置 |

- 本島の境界は手作業で設計した**18頂点の不規則な海岸線**。地形を小さな面に分割し、ソフトウェア3D描画時に線路が地面の下に隠れる問題を防止。海岸には草地の縁、クリーム色の崖、白い水際を造形。
- 高い地形は本島の外側の**独立した小島**に集約。列車線路は本島内のほぼ一定の高さに配置。
- AとBの曲線レールはそれぞれマップの異なる区域を巡り、中央駅で終わります。線路上の車両は各車両ごとに弧長と接線で動きます。
- 家・風車・木々は線路の曲線に沿った水平安全距離を検査し、島の外にはみ出さないように配置。
- 地形の静的メッシュはWebGLでは初回だけアップロード。Canvas2Dではカメラ移動時だけ静的投影を再計算し、列車のみ動的更新。
- 両路線とも「駅まで1200m」は**教育用の仮定**です。模型の見た目の距離と実距離の縮尺が厳密に一致する意味ではありません。算数は時速・距離・所要時間の正確な式で計算。グラフは全条件で時間軸0〜6分固定。

## プロジェクト・実行

`index.html`、`style.css`、`world3d.js`、`game.js` が稼働に必要です。スタンドアロンHTMLも同梱可能。ゲーム内は外部CDN・広告・アフィリエイト・第三者行動追跡なし。`noindex,nofollow`を維持。

```sh
node --check world3d.js
node --check game.js
node --test tests/*.test.cjs
python tests/quality-v05.py
python tests/ux-regression.py
python tests/visual-v06.py
```
