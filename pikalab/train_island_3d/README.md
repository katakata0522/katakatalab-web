# PikaLab 3D列車の島 v0.7 — 1画面で遊べるレイアウト

水上の広い本島、7つの高い離島、2台の列車を3Dメッシュで描く理科・算数の体験型教材。参考画像の柔らかいローポリの色調とミニチュア感を維持します。本番非公開のレビュー用試作です。

## 今回の主な変更

- **PC（980px幅以上、高さ650px以上）**：1画面を**3D模型（左）＋操作/グラフ（右）**に整理。画面を縦にスクロールせず、速さの変更→列車の走行→結果の確認→再挑戦が可能。
- **タブレット縦画面**：模型が上、操作・グラフが横並びの下部パネル。画面全体の縦スクロールを基本不要に。
- **スマホ**：3D模型が主役。そのすぐ下に2列車の速さスライダーとスタートボタン。**グラフは右上の「グラフを見る」から大きなシートを開く**ので、読めないほど小さくならない。閉じるボタン・Escapeにも対応。短い画面や文字拡大時には無理な固定をしない。
- **状態依存の主ボタン**：開始 → 一時停止/再開 → もう一度走らせる。走行中の「結果を見る」は補助ボタン。重複した「やり直す」ボタンを削除し、同じ場所で繰り返し遊べる。
- **失敗と成功**：3D世界に短い通知、操作パネルに数学的な理由を表示。グラフの説明を結果へ統合して二重説明と重なりを防止。
- **ゲーム操作中の自動スクロールを廃止**。画面が意図せず上下にジャンプしない。
- **テストを整理**。過去バージョン専用のスクロール回帰テストを削除し、現在のレイアウト/各状態のブラウザ検査に集約。

## 操作

1. AとBの速さ（12〜48km/h）をスライダーで決める。
2. 「列車を走らせる」。走行中は同じボタンで一時停止・再開。
3. 早く結果を知りたいときは「結果を見る」。両方駅に着くと結果とヒントが出る。
4. その場で速さを変えて再挑戦、または「もう一度走らせる」。

グラフは横軸0〜6分、縦軸0〜1200m。両列車とも1200mの距離を走ると仮定した算数モデルです。立体模型におけるルート実寸と教材用距離は比例していません。3Dの曲線を見回すにはドラッグ、PCのShift＋ドラッグまたはスマホ2本指で地図を移動、±で拡大縮小、⟲でリセット。

## 実装・方針

- ネイティブWebGLによる実3Dメッシュ + Canvas2Dソフトウェア3Dフォールバック。
- 島の静的メッシュ・ソートはキャッシュ、列車・風車は動的メッシュ。スタート/停止時の余計なゲームループを回さない。
- 外部CDN、広告、アフィリエイト、第三者の行動追跡なし。noindex。従来のPikaLabサイト/既存教育ツールへは影響しません。
- v0.6の地形は**広い本島と7つの離島**、家と風車の線路安全帯のチェックを継続。
