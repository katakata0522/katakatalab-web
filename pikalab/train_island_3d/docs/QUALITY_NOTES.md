# 3D列車の島：品質改善記録 v0.3（2026-10-16）

## 解消した問題と対応

| 問題 | 対応 | 検証 |
|---|---|---|
| カーブで客車が線路をはみ出す | 各客車に独立した弧長位置と接線方向を割り当てた | 曲線数学13件・ブラウザ4幅 |
| 車輪が地面に突き刺さるように見える | 車軸方向に回転させた車輪メッシュで置換 | 画面撮影・モデル動作 |
| 木が列車を隠す | 線路から距離を空けて植樹・本数を抑える | 画面撮影 |
| 水と崖の境界がぼやける | 立体形状の水際の明るい縁取りを追加 | 画面撮影 |
| 速さを操作しスタートすると列車が画面外を走る | 出発後に3D模型へスクロールして戻し、結果を島の上に表示 | UX自動操作 |
| 何を直せば成功するかわかりにくい | A/Bの先着と修正すべき速度を具体的に示す | UX自動操作 |
| グラフが答えを出発前から示す | 予定到着のガイド線を除去し、発車とともに描く | DOM確認 |
| SVGグラフを高頻度で作り直す | 描画更新を約100msごとに抑制 | コード検査 |
| モバイルの3Dキャンバスがスクロールを妨げる | 縦スワイプはブラウザに渡し、横スワイプで回転 | CSSとブラウザ検査 |
| 視点リセットで初期倍率に戻らない | 画面幅に応じた初期倍率を保存して復元 | 単体テスト |
| 早く結果だけ見たい | 出発後に「結果へ進む」ボタンを表示 | ブラウザ検査 |
| 動きを減らす設定に非対応 | 即時到着・グラフを表示 | ブラウザ検査 |

## 画面の優先順位

1. **立体模型（主役）**：水に浮かぶ島、駅、列車、線路が明瞭。
2. **速度操作（次の行動）**：初めてでも2つのスライダーと大きな出発ボタンだけで始められる。
3. **答え（その場で受け取る）**：成功/失敗と到着時間を島の上で即表示。
4. **グラフ（後から意味が分かる）**：経過時間と移動距離の2線を比較。

装飾文字・未実装のメニュー・ランク／コイン・強制チュートリアルは増やさない。ユーザーが要請した「飾りテキスト禁止」の原則を守る。

## 次に確認が必要

- Chrome/Safari/FirefoxおよびAndroid/iOSのWebGL・GPU実描画、端末温度・バッテリー消費・フレーム落ち。
- 3D地形の美術品質（断崖の連続性、自然な線路・橋の接続、駅や小物の造形）。ユーザーの参考画像にはまだ造形的に及ばない。
- 拡大文字・スクリーンリーダーの読解順序・複雑なタッチジェスチャー。
- 実際の小学生と保護者に触ってもらうユーザビリティ試験。
- 公開用CI、広告解析ポリシー検査、静的配信/PWAキャッシュ検証。

**今後の方向**：まず参考画像の島の形・建物・色・陰影の再現度を上げ、操作説明の追加ではなく見せ方そのもので遊び方が伝わる段階を目指す。
