# speed_reader 保守メモ

## 目的
画面構成・配色・文章・教材・内容クイズを保ち、読書の表示単位と中断・再挑戦を安定させる。

## 変更時のチェック
1. `node --check pikalab/speed_reader/js/app.js`
2. `node --check pikalab/speed_reader/js/comprehension.js`
3. `node --test pikalab/speed_reader/tests/*.test.cjs`
4. `cd pikalab && npm run build:all && npm run verify:build`
5. `npm run test:speed-reader-e2e`
   - 実distを配信し、320/390/667/1280pxで配置・実操作・到達性を検証する
   - `SPEED_READER_BASELINE_ROOT`には同じPR基点から構築したdistを指定する
   - CIでは既存のまなびランド比較用ビルドを再利用する
6. `python3 .github/scripts/validate_pikalab.py`

## 維持する契約
- 本文・読み仮名・出題内容を無断で書き換えない。ルビは直前の基底文字だけへ付ける
- 全内蔵作品の本文・ルビ保存を、1〜3語設定、Intl.Segmenterの対応・未対応・失敗で確認する
- 同じ本文のチャンク数変更では分かち書き結果を再利用する
- 保護者画面・タブ切替・非表示・ページ離脱では再生とカウントダウンと完了待ちを止める
- 完了と一時停止を区別し、再挑戦に前回の所要時間を加えない。結果のEscape・背景・ボタンは同じ後処理を使う
- WPMは実経過時間と同じ語数から求め、結果表示・履歴・バッジ判定で共有する
- 最新のファイル・教材・直接入力を優先し、古いFileReader完了で戻さない。保存禁止でも操作を続ける
- 内容クイズ使用時に旧結果ダイアログの不要な描画やフォーカス処理を起動しない
- 日本語入力中・修飾キー・リピート入力・ボタンや入力欄ではページ全体のショートカットを奪わない
- 通常の文字サイズとレイアウトは維持する。小画面・特大・複数語で文字が枠外へ切れる場合だけ、本文とルビが収まるサイズへ調整する
- デザイン提案は別扱いとし、共有CSS・PWA・SWの所有範囲には拡張しない
- 公開後は通常URLの新規閲覧環境と配信資産の一致を確認し、旧キャッシュの検証とは区別する
