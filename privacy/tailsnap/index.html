TailSnap プライバシーポリシー

TailSnapが何を読み取り、どこに保存し、どこへ通信する可能性があるかを説明します。

最終更新：2026年8月25日

重要な要約

TailSnapは、ユーザーが明示的に調査を開始した現在のタブだけを解析します。調査結果、閲覧履歴、個人情報を開発者・解析サービス・広告サービスへ送信しません。

1. TailSnapが扱う情報

TailSnapは、Web UIの調査、説明、コード生成、AI向け実装指示の生成に必要な範囲で、ユーザーが選択した要素と現在のページをブラウザー内で解析します。

  • 選択要素のDOM構造、表示文字、計算済みスタイル
  • 寸法、余白、配置、色、フォント、コントラスト関連情報
  • ページ内の画像・SVG・フォントなどの素材URL
  • ユーザーが選択したTailwind CSSバージョン、出力形式、言語などの設定

これらは、ユーザーが操作しているTailSnapの画面に結果を表示するために使います。元サイトのTailwindクラスや設計データを完全に復元するものではなく、計算済みスタイルから近い表現を提案します。

2. 端末内での処理と保存

ブラウザー内で処理する機能

スタイル解析、色の照合、フォント解析、WCAGコントラストの事前確認、コード生成、AI向け指示文生成、Tailwind辞典検索はブラウザー内で処理します。

端末内に保存する情報

言語、辞典のお気に入り、カスタム辞典、最近の調査履歴を拡張機能のlocalStorageへ保存します。履歴は再表示に必要な最小限のスタイル情報に限定し、ページ本文、フォーム入力値、素材URL、生成済みコードは履歴へ保存しません。

削除方法

調査履歴はTailSnap内の履歴削除操作で消去できます。ChromeからTailSnapを削除すると、Chromeの仕組みにより拡張機能のローカル保存領域も削除されます。開発者側にサーバー保存された複製はありません。

3. 外部通信

  • TailSnapは調査結果、閲覧履歴、操作ログを開発者のサーバー、アクセス解析、広告サービスへ送信しません。
  • 画像などをプレビューまたは書き出すときは、ユーザーの操作により元の素材配信元へ取得通信が発生する場合があります。TailSnapは認証情報を付けず、開発者サーバーを経由しません。
  • AI向け指示文は端末内で生成します。TailSnapがAIサービスへ自動送信することはありません。コピー後にどこへ渡すかはユーザーが決めます。
  • Tailwind CSS公式ドキュメントなどの外部リンクを押した場合は、そのリンク先が開きます。

4. Chrome権限

  • activeTab：ユーザーがTailSnapを起動した現在のタブだけを調査するために使用します。
  • scripting：明示的な起動後に、現在のタブへ調査用スクリプトとスタイルを注入するために使用します。
  • sidePanel：調査結果、コード、履歴、素材、辞典をサイドパネルへ表示するために使用します。

TailSnapは常時サイトアクセスを要求するhost permissionsや、全ページで常時動作するcontent scriptを宣言していません。

5. Pro販売・ライセンスキー

TailSnap v2.6.1ではPro販売とオンライン購入確認を行っていません。購入ボタンとライセンスキー入力は無効で、ライセンスキーを外部へ送信しません。購入確認サービスを有効化する前に、本ポリシーとChrome Web Store上の開示を更新します。

6. Chrome Web Store Limited Use

TailSnapが権限を通じて扱う情報は、ユーザーが明示的に開始するWeb UI調査・説明・デザイン変換という単一目的の提供と改善にのみ使用します。

  • パーソナライズ広告、リターゲティング広告、興味関心広告に使用しません。
  • データブローカー、広告事業者、目的と無関係な第三者へ提供しません。
  • 開発者が調査対象のページ内容を人手で閲覧することはありません。

7. セキュリティとユーザーへのお願い

TailSnapは、権限と保存情報を最小化し、リモートで配信されるコードを拡張機能内で実行しません。ユーザーは、権限を持たないページ内容や機密情報を調査・コピーしないでください。

8. ポリシーの変更

データの扱い、外部通信、販売・認証機能に変更がある場合は、変更した機能を公開する前に本ページとChrome Web Store上の開示を更新します。
