PriceMaster Pro プライバシーポリシー

PriceMaster Proは、日本の主要フリマサービス向けに手取り額の比較、出品文作成、下書き管理、明示的な自動入力を支援するツールです。何を扱い、どこに保存し、どこへ送らないのかを説明します。

最終更新：2026年10月15日

最初に知ってほしい3点

計算と文章づくりは端末内

利益計算・出品文生成・QR生成はブラウザ内で処理します。

下書きは端末内に保存

設定と下書きはChrome内に保存します。

外部送信なし

商品情報や下書きを開発者や解析サービスへ送りません。ライセンス確認の通信もありません。

1. 端末内で扱う情報

機能提供のため、次の情報をユーザーのブラウザ内で扱います。

  • 商品名、想定価格、送料、資材費、仕入れ原価などユーザーが入力した計算条件
  • 生成した出品タイトル・説明文とユーザーが保存した下書き
  • テーマ、文字サイズ等の設定

商品情報や下書きを、開発者のサーバーへアップロードする機能はありません。

2. ローカル保存

設定と下書きは chrome.storage.local に保存します。ユーザーはChromeから本拡張機能を削除することで、Chromeが管理する拡張機能用ローカルデータを削除できます。

JSONバックアップ機能を使った場合は、ユーザー自身が選んだ場所へバックアップファイルを保存します。

3. 外部通信

通常の利益計算、出品文生成、下書き保存、QR生成は端末内で処理し、入力内容を開発者や分析サービスへ送信しません。

ライセンス確認や購入確認の通信も行いません。

4. 権限

storage

設定と下書きをローカル保存するために使用します。

activeTab / scripting

ユーザーが明示的に「出品画面へ自動入力」を実行したとき、現在開いている対応出品ページへ生成済みのタイトル・説明文・価格を入力するために使用します。パスワードやCookieを取得する目的では使用しません。

contextMenus

ユーザーが選択した商品名等を右クリックし、各フリマサービスの相場検索を開く操作を提供するために使用します。

本拡張機能のcontent scriptは、manifestに列挙した対応フリマドメインに限定して動作します。

5. 第三者提供・広告・分析

商品情報、下書き、閲覧履歴を広告配信、行動ターゲティング、データ販売、アクセス解析のために第三者へ提供しません。

6. 有料の機能について

現在、有料の機能、トライアル、ライセンス確認はありません。有料の機能を追加する場合は、公開前に本ポリシーとChrome Web Store上の開示を更新します。

7. フリマ各社との関係

PriceMaster Proは個人開発による非公式ツールであり、メルカリ、LINEヤフー、楽天その他の掲載サービス各社が提供・承認・保証する製品ではありません。各サービスの仕様・料金・規約は変更される場合があります。

8. 変更

外部通信、保存対象、決済・ライセンス確認、権限などプライバシーに影響する変更を行う場合は、変更した機能の公開前に本ポリシーとChrome Web Store上の開示を更新します。
