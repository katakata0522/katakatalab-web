MaskWeb Pro プライバシーポリシー

MaskWeb Proは、画面共有・録画・スクリーンショットの前に、Webページ上の個人情報や機密情報を見えにくくするマスキング支援ツールです。何を扱い、どこに保存し、どこへ送らないのかを説明します。

呼び出したタブだけで動く

ポップアップやショートカットで呼び出した現在のタブにだけ読み込みます。全サイトの常時監視はしません。

設定は端末内に保存

マスク対象やキーワードなどの設定はChrome内に保存します。

外部送信なし

ページ内容やキャプチャ画像を開発者サーバーや解析サービスへ送りません。ライセンス確認の通信もありません。

1. 基本方針

MaskWeb Proは、画面共有・録画・スクリーンショット作成前に、Webページ上の個人情報や機密情報を見えにくくするためのマスキング支援ツールです。

v2.4.0では、インストール時からすべてのWebサイトへ常時アクセスする権限を要求しません。ユーザーが拡張機能のポップアップを開く、またはMaskWebのキーボードショートカットを実行した現在タブに対してのみ、activeTab と scripting を利用してマスキング機能を読み込みます。

マスキング対象の本文、メールアドレス、電話番号、住所、金額、認証情報候補、スクリーンショット画像などを開発者サーバーや分析サービスへ送信しません。

ライセンス確認などの外部通信も行いません。

2. 扱う情報

  • マスキング対象のWebページ内容：ユーザーが指定した要素や機密情報候補をブラウザ上でマスク（現在タブ内で処理。開発者へ送信しない）
  • マスキング用CSSセレクタ・矩形・キーワード・表示設定：ページやドメインごとの設定復元（chrome.storage.local に保存）
  • ウォーターマーク文言：スクリーンショットへの表示（chrome.storage.local に保存）
  • キャプチャ画像：ユーザー指定による保存・クリップボードコピー（ブラウザ内処理。開発者へ送信しない）
  • Chrome Managed Storageの企業ポリシー：管理対象端末で指定キーワード・スマートマスキング設定を適用（Chromeの管理ポリシーとして読み取り。開発者へ送信しない）

3. Webページへのアクセス

MaskWeb Pro v2.4.0は必須の <all_urls> コンテンツスクリプトを使用しません。

ユーザーがポップアップを開く、またはキーボードショートカットを押すという明示的な操作の後、現在のタブに限ってマスキング処理用JavaScriptとCSSを読み込みます。Chrome内部ページ、拡張機能ページなど、Chromeがスクリプト実行を許可しないページでは動作しません。

ページを別オリジンへ移動すると activeTab の一時アクセスは失効します。必要な場合は、そのページで再度MaskWebを呼び出してください。

4. スマート検出について

スマート検出は、Webページのテキストをブラウザ内でパターン照合し、金額、メールアドレス、電話番号、住所、カード番号・IPアドレス・APIキーらしき文字列等をマスキング候補として処理する機能です。

これは機密情報を完全に識別・保証するセキュリティ製品ではありません。誤検知・見逃しが起こり得るため、画面共有や公開前にユーザー自身で最終確認してください。

5. 外部通信

制作・機密データに関する外部通信は行いません。ライセンス確認や購入確認の通信も行いません。

有料の機能を追加する場合は、公開前にこのポリシーとChrome Web Storeの開示を更新します。

6. Chrome権限

  • storage: マスキング設定、ページ/ドメイン設定をChrome内に保存するために使用します。
  • activeTab: ユーザーがMaskWebを呼び出した現在タブへ一時アクセスするために使用します。
  • scripting: 明示的に呼び出された現在タブへマスキング用JavaScript/CSSを読み込むために使用します。
  • Managed Storage: 組織管理者がChromeポリシーとして配布した企業設定を読み取るために使用します。

7. 保存データの削除

ChromeからMaskWeb Proを削除すると、Chromeの仕組みにより拡張機能のローカルデータも削除されます。マスキング対象のWebページ本文やキャプチャ画像を開発者側のサーバーに保存していないため、それらについて開発者側で削除する複製はありません。

企業管理端末では、Managed Storageの設定は組織管理者のChromeポリシーに従います。

8. 注意事項

MaskWeb Proは、画面上の情報を見えにくくする補助ツールです。録画・配信・画面共有・公開画像から機密情報が完全に除去されることを保証するものではありません。Peek、一時解除、Webページの再描画、ブラウザやサイトの仕様変更等も考慮し、公開前に必ず出力結果を確認してください。
