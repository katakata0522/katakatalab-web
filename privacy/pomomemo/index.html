PomoMemo プライバシーポリシー

PomoMemoは、集中タイマーと短い作業メモをChromeのサイドパネルで記録するツールです。作業内容をどこに保存し、どこへ送らないのかを明確に説明します。

最終更新：2026年8月30日

最初に知ってほしい3点

作業メモはChrome内

メモ、集中履歴、目標、設定はユーザーのChromeプロファイル内に保存します。

外部送信なし

作業内容や利用履歴を開発者サーバー、広告、アクセス解析へ送信しません。

閲覧ページを読み取らない

host permissionやcontent scriptを使わず、Webページ本文・フォーム・閲覧履歴を取得しません。

1. PomoMemoが扱う情報

情報用途扱い
集中 / 休憩時間、タイマー状態セッション進行・再表示Chrome内保存
1行の作業メモ、完了時刻、集中時間作業ログ・日報・統計Chrome内保存
日次目標、連続日数、テーマ、通知・環境音設定表示と使い勝手の維持Chrome内保存
閲覧ページ本文、フォーム入力、パスワード、Cookie使用しません取得しない
JSON / CSV等のエクスポートユーザー自身のバックアップ・共有選択した保存先

2. 保存場所と外部通信

作業メモ、履歴、設定はChrome拡張機能用のローカルストレージへ保存します。開発者のクラウドに同期しません。

PomoMemoは、作業メモ、タイマー履歴、設定、利用イベントを開発者サーバー、広告サービス、アクセス解析サービスへ送信しません。Extension Content Security Policyでも外部接続を禁止しています。

JSONバックアップやCSV出力を利用した場合、そのファイルはユーザーが選択した場所で管理されます。PomoMemoが自動的にアップロードすることはありません。

3. Chrome権限

storage

作業ログ、メモ、タイマー設定、目標、表示設定をChrome内に保存するために使用します。

sidePanel

閲覧中のページを離れずに集中タイマーと作業ログを表示するために使用します。

alarms

Manifest V3のService Workerが常時動作しない状況でも、タイマーやセッション終了処理を補助するために使用します。

notifications

集中または休憩セッションの終了をローカル通知で知らせるために使用します。通知内容を外部へ送信しません。

PomoMemoはhost permissionsを要求しません。

4. 広告・分析・第三者提供

作業メモや利用履歴を、広告ターゲティング、アクセス解析、データ販売に利用しません。これらの情報を第三者へ提供しません。

将来クラウド同期、アカウント、外部AI等を追加する場合は、現在の「外部送信なし」という説明をそのまま流用せず、機能公開前に本ページとChrome Web Storeの開示を更新します。

5. 削除とバックアップ

  • 作業ログはPomoMemo内の履歴操作から管理できます。
  • ChromeからPomoMemoを削除すると、Chromeが管理する拡張機能用ローカルデータも削除対象になります。
  • ユーザーがエクスポートしたJSON / CSV等は、保存先でユーザー自身が管理・削除してください。
