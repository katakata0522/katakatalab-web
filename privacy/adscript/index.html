1. 概要

AdScript Studio Proは、対応する動画・広告ページ上の表示テキストや字幕をユーザー操作により読み取り、広告台本の構造をブラウザ内で整理・比較・保存するChrome拡張機能です。

解析したページ内容、保存したスワイプファイル、自社プロフィール等を開発者のサーバーへ自動送信しません。広告解析・台本リミックスの主要処理はブラウザ内で行います。

ただし、次の1つは機能上必要な明示的な外部通信です。ライセンス確認や購入確認の通信は行いません。

  1. ユーザーが「Slack / Discordへ共有」を実行した場合、生成した分析サマリーをユーザー自身が設定したSlackまたはDiscord Webhookへ送信します。

2. ページ上で参照する情報

対応ページまたはユーザーが明示的に解析を実行した現在タブから、次の情報を参照する場合があります。

  • ページタイトル
  • 表示中の広告本文、見出し
  • YouTube等でページ上に表示されている字幕テキスト
  • 動画要素の再生速度
  • 現在のページURL

これらは広告構成解析のために利用します。直近の解析結果やユーザーが保存した結果は chrome.storage.local に保存されます。

本拡張機能はパスワード入力値、Cookie、ログイン認証トークンを読み取る目的では使用しません。

3. ローカルに保存する情報

主に以下をブラウザ内へ保存します。

  • スワイプファイル／分析結果
  • タグ、メモ、お気に入り状態
  • 自社商品・ターゲット等のプロフィール設定
  • テーマ、表示設定、自動コピー設定
  • Slack / Discord Webhook URL（ユーザーが設定した場合）

保存件数・インポート件数には、ブラウザストレージの肥大化を防ぐため製品側の上限を設けています。

4. 外部通信

Slack / Discord Webhook

ユーザーが共有ボタンを押した場合のみ、分析サマリーを次のいずれかへ送信します。

  • hooks.slack.com のSlack Incoming Webhook
  • discord.com/api/webhooks/ のDiscord Webhook

v3.6.1以降は任意ドメインへのWebhook POSTを許可せず、上記の形式に一致するHTTPS URLだけを受け付けます。

有料の機能を追加する場合は、公開前にこのポリシーとChrome Web Storeの開示を更新します。

5. Chrome権限・サイトアクセス

  • storage: ローカル設定・分析結果の保存
  • activeTab: ユーザーが明示的に操作した現在タブの解析
  • scripting: 対応サイトで通常のコンテンツスクリプトへ接続できない場合に、現在タブの表示テキストをユーザー操作後に読み取るため
  • 対応サイトのコンテンツスクリプト: YouTube、Meta広告ライブラリ、TikTok上で解析機能を提供するため
  • hooks.slack.com / discord.com/api/webhooks/: ユーザー操作によるチーム共有

6. 第三者提供・販売

ユーザーデータを広告目的で販売しません。広告解析内容を開発者側で収集してプロファイリングする機能もありません。

Slack / Discordへ送る情報は、上記の限定された用途とユーザー操作に基づくものです。それぞれのサービス側でのデータ取扱いには各サービスのポリシーが適用されます。

7. データ削除

保存したスワイプファイルは拡張機能内から削除できます。Chromeから拡張機能をアンインストールすると、拡張機能用のローカル保存データは削除対象になります。
