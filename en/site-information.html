Site information

KatakataLab is a personal project by Katakata in Japan—a small lab of browser tools and guides. The English section is a focused doorway for international visitors.

Who runs this

One person: Katakata. Planning, building, checking, and updates are all done here. The Japanese site has a longer operator page if you want more context.

What the English tools are

Free browser utilities for everyday design and writing tasks—ratios, fonts, QR codes, diffs, and similar. No account required. Each English tool page includes the working UI and a short explanation.

Privacy and data

How each tool handles input is described on that tool’s page. Pages may load fonts, analytics, or libraries. Never paste credentials, private customer records, or regulated data into a tool you don’t trust.
