動きの仕組み図鑑｜KatakataLab Motion Atlas

WebアニメーションやUIの置き方・動きの仕組みを100パターン収録した、インタラクティブな動きのリファレンス図鑑です。各カードでアニメーションの通常再生・スロー再生・コマ送り確認ができるほか、動きが成立する仕組みの種明かし図解と、制作やAIへの指示にそのまま使えるプロンプト文・HTML＋CSS／Tailwindコードをコピーできます。

基本となるCSS記述と動きを抑える設定への配慮

Webアニメーションを軽く滑らかに保つ基本は、レイアウト再計算を伴う top / left / width ではなく、合成レイヤーで処理されやすい transform と opacity を中心に設計することです。さらに、OS側で「視差効果を減らす」を有効にしている利用者のために prefers-reduced-motion: reduce を必ず用意します。

.card-reveal {
  opacity: 0;
  transform: translateY(12px);
  transition: opacity 280ms cubic-bezier(0.22, 1, 0.36, 1),
              transform 280ms cubic-bezier(0.22, 1, 0.36, 1);
}
.card-reveal.is-visible {
  opacity: 1;
  transform: translateY(0);
}
@media (prefers-reduced-motion: reduce) {
  .card-reveal {
    transition: none;
    transform: none;
  }
}

この図鑑の使い方と活用シーン

「イメージに近い動きの名前が分からない」「実装の前にイージングや遅延のタイミングを目で確かめたい」「デザインカンプや制作メモに具体的な動きを言語化して伝えたい」といった場面を想定して作っています。気になるパターンを一覧から絞り込み、スロー再生で変化の順序を確認したうえで、必要な形式のコードや指示文をコピーして手元の制作に組み込めます。

すべてのプレビュー再生や検索・コピー操作はブラウザ内で完結し、登録不要ですぐ試せます。

制作・検証メモ

収録100パターンのプレビュー再生・速度変更・コードコピー機能はデスクトップ版およびモバイル幅のChrome系ブラウザで動作確認しています。CSSアニメーションの見た目やフレームレートは利用端末のリフレッシュレート・OSの視覚効果設定に依存します。詳しい確認方針はKatakataLabの検証ポリシーをご覧ください。
